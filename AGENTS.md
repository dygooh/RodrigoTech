# RodrigoTech

Um único app WPF (Windows, admin): diagnóstico/otimização (ex-ResetExplode) + firewall por aplicativo (WFP) + desinstalador avançado com varredura de sobras (RevoClean).

- Código: `src/`
- Publicar: `src/publicar.bat` → `dist/RodrigoTech.exe`
- Namespace interno: `ResetExplode` (não renomear sem necessidade)
- Firewall: `src/Firewall/` + `src/MainWindow.Firewall.cs`
- Desinstalador (RevoClean): `src/RevoClean/` + `src/MainWindow.Uninstaller.cs`
